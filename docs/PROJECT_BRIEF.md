# Renewable Planner

## Cel projektu

Program wspomagający wstępne planowanie instalacji OZE w Polsce.

Pierwsza wersja koncentruje się na lądowych farmach wiatrowych.
W kolejnych etapach system zostanie rozszerzony o:

- farmy fotowoltaiczne,
- magazyny energii,
- wspólne przyłączenie do sieci,
- projekty hybrydowe wiatr + PV + magazyn.

## Główne funkcje

1. Wczytanie lub zaznaczenie analizowanego obszaru.
2. Pobranie i przetworzenie danych przestrzennych.
3. Zastosowanie ograniczeń prawnych, środowiskowych i technicznych.
4. Wyznaczenie dostępnej powierzchni.
5. Rozmieszczenie turbin.
6. Oszacowanie godzinowej produkcji energii.
7. Obliczenie strat wake.
8. Porównywanie scenariuszy.
9. Wygenerowanie raportu z wykorzystanymi źródłami danych.

## Charakter produktu

Program jest systemem wspomagania decyzji.

Nie może przedstawiać wyników jako:
- ostatecznej opinii prawnej,
- gwarancji możliwości realizacji inwestycji,
- bankowalnej prognozy produkcji.

Każdy wynik powinien zawierać:
- źródło danych,
- datę lub wersję danych,
- zastosowaną regułę,
- poziom niepewności,
- elementy wymagające weryfikacji eksperta.

## Użytkownik docelowy

Osoba bez specjalistycznej wiedzy GIS, która chce przeprowadzić
wstępną analizę lokalizacji instalacji OZE.
